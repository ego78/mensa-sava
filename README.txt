MENSA SCOLASTICA SAVA - PWA
Pubblicazione GitHub Pages:
1. Crea un repository (es. mensa-sava).
2. Carica TUTTI i file e la cartella icons mantenendo la struttura.
3. Settings > Pages > Deploy from a branch > main / root.
4. Apri l'URL HTTPS generato.
Android: usa 'Installa app' o 'Aggiungi a schermata Home'.
iPhone/iPad: Safari > Condividi > Aggiungi alla schermata Home.
Nota: il login resta sul portale ufficiale del Comune di Sava.
